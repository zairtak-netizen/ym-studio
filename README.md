# YM Studio

Неофициальный десктопный клиент [Яндекс Музыки](https://music.yandex.ru) для Windows с темами, живыми фонами и визуализаторами.

Это веб-версия сервиса в отдельном окне с настраиваемым оформлением. Вход и подписка обычные, через сайт Яндекса. Проект не связан с Яндексом и не обходит подписку, рекламу или защиту контента.

## Возможности

- **Оформление:** 11 тем, готовые образы, свои образы, акцент из обложки, автосмена по времени, на каждый трек или для страницы.
- **Фоны:** градиент, аврора, обложка, своя картинка, эффекты (звёзды, снег, дождь, искры, боке, ретро-сетка) с реакцией на музыку.
- **Wallpaper Engine:** видео-обои из вашей библиотеки на фоне приложения и режим прозрачности, где сквозь окно видны обои на рабочем столе.
- **Визуализаторы:** столбцы, зеркало, точки, волна, осциллограф, водопад, кольцо, частицы, туннель.
- **Плеер и окно:** мини-плеер, «Сцена» на весь экран, скрытие плеера и навигации, окно поверх остальных, трей, уведомления.
- **Звук:** эквалайзер с пресетами и таймер сна.
- **Управление:** глобальные горячие клавиши, которые можно переназначить.

Панель настроек открывается клавишей F2 или круглой кнопкой справа внизу.

## Установка

1. Скачайте архив на странице [Releases](../../releases) и распакуйте его.
2. Запустите `YMStudio.exe`. Файлы из архива должны лежать рядом с ним.

Нужна Windows 10 или 11 и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). В Windows 11 он обычно уже установлен.

У программы нет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение. Если вы доверяете файлу, нажмите «Подробнее», затем «Выполнить в любом случае». Либо соберите программу сами из исходников.

## Сборка

```powershell
.\build.ps1
```

Скрипт скачивает WebView2 SDK из NuGet и собирает `dist\YMStudio.exe` компилятором C#, который входит в Windows. Устанавливать ничего не нужно.

## Устройство

- `src\Program.cs`: окно, прозрачность, трей, глобальные клавиши, связь с Wallpaper Engine.
- `src\mod.js`: внедряется в страницу. Темы, фоны, визуализаторы, панель настроек.

Подробности реализации:

- Темы переопределяют дизайн-токены сайта `--ym-*`, поэтому обновления вёрстки их почти не задевают. Эффекты плеера и навигации завязаны на префиксы классов вроде `PlayerBarDesktopWithBackgroundProgressBar_` и могут потребовать правки, если сайт их переименует.
- Обложки находятся по адресу картинки (`get-music-content`), а не по классам.
- Видео из Wallpaper Engine отдаются приложением по пути `/__yms/` на домене сайта, потому что CSP разрешает медиа только с него. Отдаются только файлы из найденной библиотеки.
- Режим прозрачности использует `DwmEnableBlurBehindWindow` с пустой областью. `TransparencyKey` не подходит: окно перестаёт получать клики. Сцены и веб-обои рисует сам Wallpaper Engine, команды идут через `wallpaper64.exe -control`.
- Эквалайзер включается в аудиограф сайта только когда он включён. Иначе путь звука не меняется.
- Если в Windows отключены анимации (`prefers-reduced-motion`), фон и эффекты замирают.

Настройки хранятся в профиле `%LOCALAPPDATA%\YMStudio\WebView2`.
